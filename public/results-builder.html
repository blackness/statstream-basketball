What goes where

The essentials are Place, Name, and Time. Everything else is optional but enriches the output.

  • Place / Bib — finishing position & bib number
  • Name — single column, or First + Last
  • Time — finish time (chip or gun)
  • Category / Gender / Age — for filtering
  • Split — segment times like 1K, Run 1, T1
